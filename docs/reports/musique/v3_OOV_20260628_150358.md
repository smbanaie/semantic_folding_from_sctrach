## Analysis

**OOV expansion degrades performance** on MuSiQue. The WordNet synonym + FAISS nearest-neighbor expansion introduces noisy terms that dilute the semantic fingerprint. Key observations:

1. **FAISS IVFFlat built per query** — 44× index rebuilds, each taking ~4s on 23,991 vectors × 4096 dim = 176s overhead
2. **Total runtime**: 458s (7× slower than baseline 63s)
3. **Noise injection**: OOV terms like "wolf v" → "wolf vishniac" or "islamic denomination" expand to similar but irrelevant vectors, reducing precision

**Recommendation**: Keep `--no-oov-expansion` for all future MuSiQue runs. OOV expansion only helps when vocabulary coverage is very poor — MuSiQue's 23,991 phrase vocabulary already covers most query terms well.
