## Analysis

### Dataset Characteristics

NQ-REaR has ~10 passages per query with 1-2 gold passages. Unlike PopQA:
- Queries are natural language questions (not entity lookups)
- Candidate pool is larger (10 vs 2 passages)
- Gold passages may not contain the exact query terms

### Why SF Underperforms BM25

1. **Lexical gap**: NQ queries use different vocabulary than passages
   - Query: "who has the oldest team in the nba"
   - Passage: "Eddie Gottlieb... Basketball Association of America"
   
2. **Semantic mismatch**: SF's phrase extraction misses key terms
   - Some queries have 0 valid phrases (e.g., "where does sleeping freshmen never lie take place")
   - OOV phrases reduce fingerprint quality

3. **Candidate pool size**: With 10 passages, discrimination is harder
   - SF's sparse fingerprints have less resolution
   - BM25's term frequency scoring is more robust

### Failure Patterns

- **Query 17**: "where does sleeping freshmen never lie take place" → 0 valid phrases
- **Query 34**: "who sings you ca n 't get what you want" → OOV terms
- **Query 37**: "who hosted they think it 's all over" → OOV terms

## Reproduction

```bash
# Convert dataset
.venv\Scripts\python -c "
from semantic_folding.dataset_benchmark.adapters import get_adapter
from pathlib import Path
a = get_adapter('nq_rear')
a.convert_to_musique_format(Path('data/nq_rear/raw'), Path('data/nq_rear/converted'), max_queries=100)
"

# Run SF benchmark
.venv\Scripts\python -m semantic_folding.dataset_benchmark.generic_benchmark all \
  --dataset nq_rear --jsonl data\nq_rear\converted\nq_rear.jsonl --max-queries 100

# Run BM25 baseline
.venv\Scripts\python -m semantic_folding.dataset_benchmark.bm25_benchmark \
  --dataset nq_rear --jsonl data\nq_rear\converted\nq_rear.jsonl \
  --run-dir outputs\nq_rear_benchmark\runs\run_20260615_190406 --query-end 100
```
