## Analysis

### Why BM25 Achieves Perfect Scores

PopQA has a trivial structure for lexical matching:
- Each query contains the entity name (e.g., "What is **George Rankin**'s occupation?")
- The gold passage title is the entity name ("George Rankin")
- BM25's term frequency matching trivially ranks the gold passage #1

### Why SF Gets MRR=0.980 (not 1.0)

SF fails on 2 queries where:
1. Semantic similarity doesn't align with lexical overlap
2. The query phrases don't match the passage vocabulary well
3. The candidate pool is too small (only 2 passages) for semantic discrimination

### Key Insight

PopQA is **not a good benchmark for SF** because:
- The task is trivial for lexical matching (BM25 perfect)
- The candidate pool is too small (2 passages)
- No semantic understanding is required

## Reproduction

```bash
# Convert dataset
.venv\Scripts\python -c "
from semantic_folding.dataset_benchmark.adapters import get_adapter
from pathlib import Path
a = get_adapter('popqa')
a.convert_to_musique_format(Path('data/popqa/raw'), Path('data/popqa/converted'), max_queries=100)
"

# Run SF benchmark
.venv\Scripts\python -m semantic_folding.dataset_benchmark.generic_benchmark all \
  --dataset popqa --jsonl data\popqa\converted\popqa.jsonl --max-queries 100

# Run BM25 baseline
.venv\Scripts\python -m semantic_folding.dataset_benchmark.bm25_benchmark \
  --dataset popqa --jsonl data\popqa\converted\popqa.jsonl \
  --run-dir outputs\popqa_benchmark\runs\run_20260615_172138 --query-end 100
```
